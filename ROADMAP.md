# Panel Log 3030 — план

## Сделано
- Приём вывода принтерного порта TB5 (PTX/REF) через USB-RS232 (FT232R, 9600 8N1)
- Разбор графического вывода NFS2-3030 (ESC *), таблица шрифта, иврит visual→logical
- Список событий, «как на бумаге», отправка: WhatsApp / PDF (иврит или иврит+русский) / файл лога
- Поле «Объект»: запоминается, подсказки, сохраняется рядом с логом

## Дальше
- Убрать кнопку «Тест TX», галочку «HEX» и кнопку «Копировать» (переходник проверен; всё отправляется через «Отправить»)
- На месте «Тест TX» — кнопка «Скачать на телефон» (сохранить отчёт/лог в память телефона); «Отправить» остаётся
- Переключатель языка интерфейса приложения: русский / иврит
- База объектов и неисправностей, статусы (новая / ждёт одобрения / одобрена / устранена), сверка с прошлым визитом
- Фото и причина в карточке неисправности, отметка «к оплате клиентом»
- Сервер на домашнем сервере, синхронизация нескольких техников
- Веб-интерфейс для начальника (иврит/русский), печать отчёта
- Импорт таблицы начальника по фото (ИИ)
- Формат даты «месяц день,» для панелей с другими региональными настройками
