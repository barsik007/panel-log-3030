# Panel Log 3030 — план

## Сделано
- Приём вывода принтерного порта TB5 (PTX/REF) через USB-RS232 (FT232R, 9600 8N1)
- Разбор графического вывода NFS2-3030 (ESC *), таблица шрифта, иврит visual→logical
- Список событий, «как на бумаге», отправка: WhatsApp / PDF (иврит или иврит+русский) / файл лога
- Поле «Объект»: запоминается, подсказки, сохраняется рядом с логом
- Название G1 Hotelo и иконка; язык интерфейса русский/иврит; «Настройки» (скорость, расшифровка, язык); кнопка «Скачать» (PDF/лог в «Загрузки/G1 Hotelo»); убраны «Тест TX», «HEX», «Копировать»

## Дальше — локальная версия (без сервера)
- Объекты: создать один раз (название, адрес/заметка), выбрать перед снятием лога; подсказка объекта по имени панели
- История логов по объекту: дата, время, число событий; открыть, отправить, сравнить любые два
- Каждый новый лог автоматически сравнивается с предыдущим логом объекта: ✅ устранено / ⏳ осталось / 🆕 новое / 🔁 повторное
- Неисправности объекта — общий список с историей (появилась, пропала, отметки, фото), не привязан к визитам
- Карточка неисправности: быстрые действия (починил, заменил датчик, почистил, заменил базу, проводка, חסר גלאי…) + «Другое…»; список действий редактируется в Настройках
- Платные по умолчанию: действия, автоматически ставящие «к оплате клиентом» (חסר גלאי; полный список пришлёт пользователь)
- Предупреждение о расхождении: отмечено «починил», а панель ещё видит; или пропала без отметки
- Отчёт за период: «с прошлого лога» или «с даты…»; в шапке объект и период; WhatsApp/PDF, иврит или иврит+русский
- Поиск и фильтры (адрес, место, тип проблемы, зона), сводка по шлейфам
- Хранение в SQLite на телефоне с UUID — готово к будущей синхронизации

## Потом

- Фото и причина в карточке неисправности, отметка «к оплате клиентом»
- Сервер на домашнем сервере, синхронизация нескольких техников
- Веб-интерфейс для начальника (иврит/русский), печать отчёта
